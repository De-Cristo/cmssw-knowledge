# Glossary

## Event

The primary unit of physics data processing. Modules access typed products
associated with the current event.

## EventSetup

The framework facility through which modules access non-event state organized
into records, commonly including geometry and conditions information.

## Module

A configured framework component that participates in processing transitions.
Specific module categories have different production, filtering, analysis, or
input/output responsibilities.

## Plugin

A compiled implementation made discoverable to the framework and selected by
configuration.

## Process

The top-level configured description of a CMSSW job, including modules,
services, paths, tasks, schedules, and options.

## Provenance

Metadata describing how a stored data product was produced and the
configuration associated with its production.
