# Subsystems

Subsystem pages are compact maps, not exhaustive file listings. Each page
should identify:

- Responsibility and boundaries
- Important packages and public interfaces
- Python configuration entry points
- Inputs, outputs, and external dependencies
- Representative tests or runnable examples
- Connections to architectural concepts and workflows

The first catalog pass will prioritize `FWCore`, `DataFormats`,
`Configuration`, `Geometry`, reconstruction, simulation, trigger, DQM, and
validation.
