# Architecture

This section will explain the stable concepts that connect many CMSSW
subsystems:

- Process construction, schedules, paths, tasks, and transitions
- Framework module types and plugin discovery
- Event data, product lookup, provenance, and persistence
- Services and framework callbacks
- EventSetup records, conditions data, and intervals of validity
- Concurrency, streams, luminosity blocks, and runs
- Geometry, input/output, and heterogeneous execution

Architecture notes should answer both **what the abstraction means** and **where
its behavior is implemented**.
