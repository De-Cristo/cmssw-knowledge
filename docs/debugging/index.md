# Debugging

This section preserves diagnostic knowledge that is easy to lose after a
problem is fixed.

A debugging note should include:

- Observable symptom and exact error signature
- Smallest reproduction available
- Responsible configuration, module, or data dependency
- Investigation steps that distinguished the cause
- Resolution and validation
- CMSSW revision and environment constraints

Avoid storing credentials, private infrastructure details, or unpublished data
in this public site.
